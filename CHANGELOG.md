# Changelog

Newest first. The headline version here is the one shown in Settings and in the service worker cache name
(`tripnest-v<version>-<hash>`). Each entry is also shown inside the app as "What's new".

## 1.1.0 - 2026-10-26
- New: a "New version available" banner and an "Update now" button, so updates no longer happen silently half-way.
- New: Settings page with the version, last updated date, "What's new", a settings check, appearance, and storage.
- New: Undo and Redo for edits, with a History list of recent changes.
- New: search across all your trips from one place.
- New: Help page and a welcome card for first-time use.
- New: app lock with a PIN or password.
- New: dark mode switch (Automatic, Light or Dark) and a text size setting.
- New: the app says when you are offline, and warns when device storage is nearly full or cannot save.
- Backup files now record the app version that made them.

## 1.0.0 - 2026-09-01
- First release: trips, itinerary, reservations, packing, expenses with exact splits, budget, to-do, notes, documents,
  Explore, maps, weather, backups (optionally password protected), merging trip files between phones, and offline use.
